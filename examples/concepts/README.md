# Concepts de exemplo (entrada da rota `mesh`)

- `teapot.png` — imagem de exemplo do repositório **TripoSR** (licença MIT), usada como fixture de
  entrada da rota `mesh`. O asset publicado é gerado pelo Forge3D; a imagem é só o `origem`.
- A imagem precisa de fundo neutro/alfa **ou** o provider deve rodar com
  `FORGE3D_I23D_REMOVER_FUNDO=1` (usa `rembg`).
- Rode a partir da raiz do repo para o caminho relativo `examples/concepts/teapot.png` resolver.
